# Hyuga-Sound
Hyuga Sound - Guitar Toolkit

just run - npm start
compile - npm run build
compile for win - npx electron-builder --win
compile all - chmod +x /build-all.sh and run it

-- FOR LINUX --
chmod +x install.large.sh
install.large.sh require sudo pacman -S imagemagick

chmod +x install.sh
install.sh - lite install version (move desktop and icons to share directories, and add mime type)

chmod +x uninstall.sh
uninstall.sh - uninstall all files, and from large verion
